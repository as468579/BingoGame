# 各遊戲卡牌庫

每種遊戲有自己的卡牌檔案，卡片 ID 只需在該遊戲內唯一。卡片名稱、外觀、抽取啟用狀態與題目難度均可各自設定。

| 遊戲 | 卡牌檔案 | 目前用途 |
|---|---|---|
| Bingo／單人賓果 | `src/games/bingo/cards.json` | 個人效果卡與舊示範問答卡；目前手牌介面仍暫停使用 |
| Team Bingo／團隊賓果 | `src/games/teambingo/cards.json` | 特殊格抽出的隊伍共用效果卡，題目另從題庫抽選 |
| Bridge Bingo／橋牌賓果 | `src/games/bridge/cards.json` | 預留效果卡庫，目前為空；三色數字牌仍依盤面尺寸動態產生 |

修改後重新啟動伺服器載入。卡庫放在伺服器原始碼目錄，不直接提供給瀏覽器下載。

## 團隊賓果卡片格式

```json
{
  "id": "my-card",
  "name": "卡片名稱",
  "symbol": "✦",
  "theme": "gold",
  "type": "能力",
  "description": "卡片說明",
  "effect": "能力待定",
  "questionDifficulty": null,
  "enabled": true
}
```

- 整份檔案為 JSON 陣列；`id` 與 `name` 不可空白，同一檔案的 ID 不可重複。
- `theme` 控制既有卡面配色，例如 `gold`、`green`、`violet`。所有遊戲仍可共用卡面與卡背元件。
- `effect` 是效果說明文字；填入文字不會自動實作能力。實際能力須在對應遊戲的規則模組實作。
- Team Bingo 已實作 `effectId: "team-time-plus-2m"` 的「加時」（黑色懷錶）：暫不限題目難度，房主判定答對時增加自己的隊伍 120 秒行動時間；答錯、取消或未判定就結束不加時。完成操作仍會換人，重送不重複加時。此卡只在 Team Bingo 的卡庫中啟用。
- `questionDifficulty` 保留卡牌與題目難度的對應設定（簡單／普通／困難／難度陣列／null）。目前團隊賓果共通規則暫時忽略此欄位，所有卡片與「下一題」都從全題庫抽題。設定不會傳給玩家。
- `enabled: false` 會停止新抽卡，但不刪除已取得的卡片；已有卡片仍可使用。請保留已使用的 ID，暫停發卡時以停用代替直接刪除，避免舊手牌找不到定義。
- Team Bingo 的題目從 `questions.json` 抽選，不放在卡片檔案中。
- 原版 Bingo 仍沿用舊問答格式，卡片另須提供 `question`、2～4 個文字 `options` 與從 0 起算的 `answer` 索引，現有三張卡已保留完整格式。

## 模組關係

效果卡的手牌、預覽、抽卡與作答介面直接顯示 `effect`，不顯示 `description`。答錯一律不觸發效果，結果只顯示「回答錯誤」，隱藏效果文字；卡片消耗與換人規則維持不變。

各遊戲的 `card-catalog.js` 只載入自己的 `cards.json`。遊戲註冊介面以 `cardLibrary` 提供該遊戲的定義，抽卡與用牌仍由該遊戲的規則處理。

`src/shared/card-library.js` 只負責共通的檔案驗證、啟用卡片抽選與公開欄位過濾，不匯入任何遊戲的內容或效果。

共通格式與隔離測試：`node --test test/card-library.test.js`。

加時卡效果與還原測試：`node --test test/team-time-card.test.js`。上一步會撤回這張卡增加的時間並退回卡片，但不退還實際已花掉的行動時間。

Team Bingo 新增「提示」卡（`team-hints-plus-2`、燈泡圖示）：不限題目難度，答對增加該隊 2 次「提示隊員」，答錯或未判定即結束均無效果。效果只套用一次；上一步退回卡片並撤回增加次數，但不退還已使用的提示。重新開局恢復每隊 3 次。

另有「禮物(飄雪結晶)」卡（`team-snow-crystals-20`）：難度設定簡單、普通，目前仍依全卡牌不限難度規則抽題。答對記入該隊飄雪結晶 ×20，累加至最終結算，與連線獎品合計；不影響盤面、勝利條件、提示次數或行動時間。答錯或未判定結束不發獎；存檔保留，上一步撤回對應獎勵，重新開局清空。

## 每局卡牌數量

Team Bingo 的加時、提示（燈泡）、禮物(飄雪結晶)、禮物(傳送石)、禮物(突襲卷)各設定 `copiesPerGame: 2`，全場所有隊伍共用 10 張卡池，依剩餘實體張數隨機抽取，不放回。卡片使用後不補回卡池；抽完時特殊格仍可佔領並換人，但不再發卡。上一步同步還原抽卡數量與手牌，重新開局或套用設定會補滿卡池。每房獨立計數，存檔保留；舊存檔依手牌與歷史中仍可辨識的卡片實例回推已發張數，保留已發卡而不額外補發。

「禮物(傳送石)」（`team-teleport-stones-4`）：禮物圖示，答對於該隊最終結算累計傳送石 ×4，答錯無獎勵；每局全場 2 張。難度設定為 `["簡單", "普通"]`，目前仍依全卡牌不限難度的共通規則抽題。沿用結算獎勵的存檔、上一步與重開局機制。

「禮物(突襲卷)」（`team-raid-tickets-2`）：禮物圖示、普通難度設定、每局全場 2 張。答對為該隊累計突襲券 ×2，結算時與既有同物品獎品合併並使用原突襲券圖示；答錯或未判定結束無獎勵。卡名沿用「卷」，結算物品使用既有標準名稱「突襲券」。
