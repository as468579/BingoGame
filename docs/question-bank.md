# 團隊賓果題庫

編輯 `src/games/teambingo/questions.json`，儲存後重新啟動遊戲伺服器。題庫只在伺服器載入，不放在公開網頁目錄。

目前包含六道「組對任務」選擇題、十道「軼聞趣事」題目（兩道口頭申論題、八道選擇題）、五道「無用知識」選擇題，以及四道「突襲週王」選擇題（兩題簡單、兩題困難），合計 25 題。可以提供一般文字格式的題目、選項與參考答案，再整理進此檔案。

## 每題格式

```json
{
  "id": "q-001",
  "category": "活動知識",
  "difficulty": "普通",
  "question": "這裡填入題目？",
  "options": ["選項一", "選項二", "選項三", "選項四"],
  "correctAnswer": "B",
  "enabled": true
}
```

- 整份檔案是一個 JSON 陣列；每題 `id` 必須唯一且不可空白。
- `question` 不可空白，`options` 須有 2～4 個非空白選項，依序對應 A、B、C、D。
- `correctAnswer` 填現有選項的字母，大小寫皆可，也可留空字串或省略。玩家提交答案或作答逾時、等待判定時，只有房主會收到並看到「正確答案：選項與內容」；答案留空則顯示空白，不自動猜測或判分。
- `category` 可省略；`enabled` 預設為 `true`，改為 `false` 即暫停抽到該題。
- `difficulty` 填「簡單」、「普通」或「困難」，未填時預設為「普通」。難度只供伺服器抽題使用，不會傳送給玩家或顯示在作答視窗。
- JSON 不支援註解；最後一個欄位或題目後面不能多留逗號。載入時會檢查格式並指出錯誤題號。

口頭申論題設定 `"type": "oral"`，不填 `options`，`correctAnswer` 可填完整文字參考答案或留空。玩家口頭作答後按「已回答」，房主在判定階段才會看到參考答案，其他人不會收到。逾時仍交由房主判定，卡片消耗與換人規則相同。

## 抽題與判定

目前所有種類效果卡都從全題庫啟用且本局尚未出過的題目中等機率抽一題，不限制分類或難度。出題紀錄由整個房間共用，各隊不會抽到本局已出過的題目；題目出現時即記錄，答對、答錯、逾時或房主結束作答都不重新放回。上一步不清除已出題紀錄，避免重看答案後再抽到同題。

目前團隊賓果的共通抽題規則暫時忽略卡牌的 `questionDifficulty` 設定，現在與日後新增的卡片都能抽到三種難度，包括口頭申論題。欄位保留供之後恢復卡牌與難度對應；作答時間仍依實際題目難度決定。詳見 [各遊戲卡牌庫](card-libraries.md)。

沒有尚未出過的啟用題目時，會拒絕使用並保留卡片與回合，不重複抽題。重新開局會清空出題紀錄；存檔、重新整理與重連都會保留紀錄。舊存檔升級時會記錄仍保存在目前作答或操作歷史中的題目，無法回溯未被保存的更早題目。

用牌者點選答案並提交後，由房主判定正確或錯誤；不因參考答案自動判分。所有題目都停用或題庫為空時，無法開始新的卡片作答，卡片不會被扣除。

房主可在作答中、提交答案後或逾時待判定時按「下一題」。原題保留為本局已出過，從全題庫抽取新題，並依新題難度重新給予完整作答時間；舊選項、口頭回答狀態及逾時標記清除。全房同步新題，不額外消耗卡片、不換人，隊伍行動計時繼續暫停。已判定正誤後不能換題；沒有可用新題時保留目前題目及其截止時間。

已抽出的題目、選項與參考答案會保存在當次作答資料中。重新啟動後即使修改或移除了原題，進行中的作答仍沿用抽出時的內容；後續抽題才使用新題庫。

## 測試

題庫格式與抽選測試：`node --test test/question-bank.test.js`。

完整回歸測試：`npm test`。

## 作答時限

作答時間依抽到的題目難度決定：簡單 10 秒、普通 20 秒、困難 30 秒，畫面顯示剩餘時間，不顯示難度標籤。到期後停止作答並進入等待房主判定，標註未於時限內作答，不自動決定正誤。等待房主判定沒有作答倒數，隊伍行動時間仍暫停。

以伺服器時限為準，逾時的提交與取消都會被拒絕；到期前已提交的答案維持有效。重新整理、重連與伺服器重新啟動保留原截止時間，不重新補時。舊的進行中題目若尚無截止時間，首次載入會依題目難度設定時限；缺少難度時依普通題給予 20 秒。
