# 團隊賓果題庫

編輯 `src/games/bingonext/questions.json`，儲存後重新啟動遊戲伺服器。題庫只在伺服器載入，不放在公開網頁目錄。

目前包含三道示範題與六道「組對任務」題目。可以提供一般文字格式的題目、選項與參考答案，再整理進此檔案。

## 每題格式

```json
{
  "id": "q-001",
  "category": "活動知識",
  "difficulty": "普通",
  "question": "這裡填入題目？",
  "options": ["選項一", "選項二", "選項三", "選項四"],
  "correctAnswer": "B",
  "enabled": true
}
```

- 整份檔案是一個 JSON 陣列；每題 `id` 必須唯一且不可空白。
- `question` 不可空白，`options` 須有 2～4 個非空白選項，依序對應 A、B、C、D。
- `correctAnswer` 填現有選項的字母，大小寫皆可，也可留空字串或省略。玩家提交答案或作答逾時、等待判定時，只有房主會收到並看到「正確答案：選項與內容」；答案留空則顯示空白，不自動猜測或判分。
- `category` 可省略；`enabled` 預設為 `true`，改為 `false` 即暫停抽到該題。
- `difficulty` 填「簡單」、「普通」或「困難」，未填時預設為「普通」。難度只供伺服器抽題使用，不會傳送給玩家或顯示在作答視窗。
- JSON 不支援註解；最後一個欄位或題目後面不能多留逗號。載入時會檢查格式並指出錯誤題號。

## 抽題與判定

使用一張隊伍卡片時，從符合卡牌難度設定的啟用題目中等機率抽一題，允許再次抽到相同題目。

在伺服器 `src/games/bingonext/cards.json` 的卡牌定義中，設定 `"questionDifficulty": "困難"`，即可讓強力卡只抽困難題；也可設定「簡單」或「普通」。`null` 表示不限難度，目前三張示範卡暫時維持此設定，卡牌強弱之後再決定。設定值只取自伺服器，不能由玩家指定。詳見 [各遊戲卡牌庫](card-libraries.md)。

沒有符合難度的啟用題目時，會拒絕使用並保留卡片，不會改抽較簡單的題目。

用牌者點選答案並提交後，由房主判定正確或錯誤；不因參考答案自動判分。所有題目都停用或題庫為空時，無法開始新的卡片作答，卡片不會被扣除。

已抽出的題目、選項與參考答案會保存在當次作答資料中。重新啟動後即使修改或移除了原題，進行中的作答仍沿用抽出時的內容；後續抽題才使用新題庫。

## 測試

題庫格式與抽選測試：`node --test test/question-bank.test.js`。

完整回歸測試：`npm test`。

## 作答時限

題目出現後有 60 秒提交答案，畫面顯示剩餘時間。到期後停止作答並進入等待房主判定，標註未於時限內作答，不自動決定正誤。等待房主判定沒有作答倒數，隊伍行動時間仍暫停。

以伺服器時限為準，逾時的提交與取消都會被拒絕；到期前已提交的答案維持有效。重新整理、重連與伺服器重新啟動保留原截止時間，不能藉此補滿一分鐘。舊的進行中題目若尚無截止時間，首次載入會設定 60 秒。
