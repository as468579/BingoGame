# Alberta Events｜多人自訂尺寸賓果

使用 Node.js 22 以上，無第三方套件，不需 npm install。

程式依職責拆分為後端 Domain／Application／Infrastructure／HTTP，以及前端 State／Storage／Network／Views。目錄、物件關係圖及資料流請見 [架構說明](docs/architecture.md)。`server.js` 與 `public/client.js` 僅為啟動入口。

```powershell
npm start
```

開啟 http://localhost:3000。其他裝置需透過同一台伺服器的位址，例如同一個區域網路中的 `http://192.168.1.100:3000`（請換成主機實際 IP，並允許防火牆的 TCP 3000 連入）。若要讓不同網路的朋友加入，請部署到支援長連線及持久磁碟的 Node.js 主機，使用 HTTPS；請勿使用純靜態網頁主機。`PORT` 可調整連接埠，`DATA_DIR` 可指定持久存檔目錄。

## 玩法

房主可在準備階段使用「盤面尺寸」選擇 3×3 到 9×9（預設 5×5）。N×N 使用 1～N²，各數字一次，先完成 N 條線獲勝。套用不同尺寸會同步重設所有玩家的盤面並取消準備；遊戲開始後需先重新開局才能改尺寸。尺寸會隨房間存檔，重連及重啟後保留；舊房間仍維持 5×5。

### 朋友專用連線頁

朋友可開啟 `http://你的Public-IP:3000/join`，輸入暱稱與房號加入。房主建立房間後，可在「邀朋友入座」填入完整公開網址，例如 `http://你的Public-IP:3000`，按「儲存網址」後複製邀請。產生的 `/join?room=房號` 連結會自動帶入房號，朋友只要填暱稱。公開網址只保存在房主目前瀏覽器；清空欄位並儲存可恢復使用目前網站網址。這項設定只影響分享連結，路由器轉送與防火牆仍需事先開通。

1. 輸入暱稱並建立房間，點房號複製邀請連結。朋友輸入暱稱與房號加入，最多 16 人。
2. 在自己的盤面輸入畫面提示的數字範圍，每個數字使用一次，或按隨機排列。完成後按準備；準備後仍可取消準備修改。
3. 至少 2 人且全員準備後，房主可以開始。依加入順序輪流點擊自己盤面的未選號碼，房主會看到確認視窗（房主自己選號也需確認）。按「確認此號碼」後才同步標記、計算連線並換下一位；按「拒絕，換下一位」則不標記、不計分，直接換下一位，被拒絕的號碼仍可再次選擇。
4. 點擊玩家清單可查看他人的盤面，點自己的名字返回。伺服器只公開盤面及遊戲資訊，不公開玩家憑證。
5. 橫、直、兩條對角線皆可得分，N×N 先完成 N 條線獲勝；同一個號碼可使多位玩家同時獲勝。房主可重新開局，原盤面保留、所有人重新準備。
6. 目前玩家離線時，先等待自動重連；房主也可按「略過目前離線玩家」。待確認期間所有玩家暫停選號，房主必須先確認或拒絕；房主離線時會等待其重連，確認視窗會自動恢復。待確認號碼一併存檔，伺服器重啟後仍可處理。房主身分固定保留，其他玩家無法代替房主確認或重新開局。

## 重連與存檔

房主可在盤面下方或待確認視窗按「上一步」，一路退回本局剛開始：清空已選號碼、連線成績與待確認號碼，由第一位玩家選號，保留所有玩家的盤面與準備狀態。例如撤回「確認」會取消標記與成績並回到待確認視窗，再按一次則撤回該次選號。勝出後也可撤回最後的確認，恢復遊戲。更新前沒有完整紀錄的較早部分，最後一步會直接回到開局狀態，無法重建當時每次拒絕或略過的順序。重新開局會清除本局撤回紀錄；紀錄會存檔並在伺服器重啟後保留。

- 使用 SSE 同步，15 秒心跳，自動重連後取得完整最新狀態。短暫斷線期間停用選號，恢復後重新同步。
- 以「房號＋玩家 ID」辨認玩家，原暱稱欄位現在是玩家 ID。相同房間輸入完全相同的 ID（區分大小寫）即可恢復原盤面、準備狀態及房主身分，遊戲開始後也能恢復；不同 ID 為不同玩家。這是免密碼的房間身分識別，知道同一 ID 就能使用該身分，並非具密碼保護的帳號登入。
- 每個分頁用 sessionStorage 記住正在使用的 ID 與憑證，重新整理、短暫斷線會自動恢復；不同無痕視窗可輸入不同 ID。點頁尾「切換玩家 ID」可重新輸入。同瀏覽器的「複製分頁」可能複製原分頁資料，這時可用此按鈕切換。升級時第一個重新整理的分頁會接手舊的共用身分；其他分頁請輸入各自 ID。
- 操作遇到網路問題最多自動重試 4 次，每次沿用相同操作 ID，伺服器去重，避免重複選號。超出次數會顯示錯誤；可重連後查看最新狀態。
- 每個成功操作同步寫入 `data/rooms.json`，以暫存檔替換。重啟伺服器後保留房間、盤面、已選號碼、回合及身分。未按準備的編輯內容只是本地草稿，重新整理不保留。
- 關閉分頁、清除瀏覽器資料或換裝置後，可重新輸入原房號與玩家 ID 恢復身分；需保留伺服器存檔。公開邀請網址仍儲存在共用 localStorage。
- 本版本為單一 Node.js 程序，房間不自動過期，最多 1,000 房。正式大量使用時需改用資料庫、房間清理與跨程序同步；請勿同時啟動多個程序共用存檔。玩家 ID 為免密碼識別，不是具密碼保護的帳號系統。

## 驗證

```powershell
npm run check
npm test
```

測試涵蓋盤面驗證、權限、輪流選號、重送去重、共同獲勝、狀態存檔、SSE 重連、多分頁在線狀態、前端草稿與舊快照、分頁身分隔離、API 重試及模組靜態路由。前端直接載入原生 ES modules，請透過伺服器開啟，不要直接開 HTML 檔案。
